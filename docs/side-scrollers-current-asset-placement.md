## Quality and publishing gates

- References: `docs/side-scrollers-25-individual-reference-review.md` and current `assets/platform-worlds.js`; never copy protected game sprites, level maps or audio.
- Stage 1 and Stage 2 props are view-culled, game-selected, and draw **before** walkable surfaces. Enemy logic and platform colliders were not modified.
- Current Android landscape control behavior, live HTTPS game loading, FPS, foot planting, hit sync, and story movie files need separate device/browser verification. No gameplay visual or film completion claim is made.
- Before producing feature-film-style 3D game art, inspect the approved master poster and create true 3D production assets rather than labeling vector illustrations as 3D renders. Use free tools only; stop where provider cost is unknown.
