# Individual counterpart-informed design review — 25 side-scrollers

This is a **mechanics-based reference review**, not a claim that the original games were played or frame-by-frame inspected during this update. Reference titles and each Super Paw Heroes game's identity were verified against `assets/platform-worlds.js`. Use original Super Paw Heroes assets, story, maps, and level geometry; do not reproduce copyrighted maps, sprites or audio. Each game's six chapters should be reviewed independently before adjusting stage generation. Keep the $0 budget and Android landscape controls.

- **Counterpart:** Super Mario World
- **Core gameplay to evaluate:** running jump arcs, stomp rebounds, safe landing strips.
