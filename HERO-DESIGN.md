# Whisker and Luna: shared visual source

The exact user-supplied poster is retained at `assets/whisker-luna-master.png`.
Its SHA-256 and canonical character details are recorded in `assets/heroes-master.json`.
The WebP display copy is an optimized derivative, not a replacement for the original.

Whisker has orange tabby fur, green eyes, a swept orange crest, red/navy/gold armor,
a paw shield, a paw belt buckle and a red cape. Luna has silver-white tabby fur,
violet eyes, swept silver/lavender hair, purple/silver/cyan armor and crescent emblems.
Do not exchange their facial identities, emblems, colors, belts or approved voices.

## Working implementation

- `assets/whisker-master.glb` and `assets/luna-master.glb` are the editable/exportable
  model studies. Named nodes have semantic attachment regions in `extras`.
- `assets/super-paw-rig-runtime.js` applies shared procedural head, limb, cape and tail
  motion, blinking and foot-ground correction. These are runtime node transforms;
  the GLB files are static mesh exports with no skinning skeleton or animation clips.
- `assets/super-paw-rig.js` bundles both models and the runtime for same-origin/offline use.
- Crystal Catacombs and `hero-models.html` use that same geometry and pose code.
  Battery saver uses lower-resolution sphere geometry and omits small accent details.
- Website/arcade/studio/universe pages show the same approved artwork and character
  reference. Newly generated game drafts embed the shared models, pose code and poster.
- Existing videos, drawings and other published assets are not regenerated by this change.
  New media must use the original poster and registry as their production reference.

## Update workflow

1. Refine the named GLB model nodes, or refine the shared runtime source.
2. Run `node scripts/pack-hero-models.mjs`.
3. Run `node scripts/sync-hero-assets.mjs`.
4. Run `node tests/heroes.test.cjs`.
5. Inspect both heroes from front/back and in idle/walk/run/attack poses. Test on Android
   before claiming device performance. Keep the original reference hash unchanged unless
   the owner explicitly approves replacement artwork.

## Quality limits

This is a refined procedural model study, not an exact recreation of the cinematic poster.
Fine fur, production texture maps, retopology, an exported skinned skeleton, expressive
facial blendshapes and a cinematic animation pipeline remain future production work.
Keep these limits visible; do not call the models perfect or claim unseen films were updated.
