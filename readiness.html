    Install and test on Android

    1. Open the hosted HTTPS home page in Chrome. Wait until it says offline files are saved.
    2. Use Install when offered, or Chrome’s menu → Add to Home screen. Browser support varies.
    3. Play each game, pause and resume, switch apps, rotate your phone, and try Low Graphics.
    4. Close the page, turn on airplane mode, then reopen the saved home page and games.
    5. Test checkpoint saving, resume and clear-save. Export operations backups before clearing browser data.

    Report any freeze, missing button, lost save or stutter before release. Installation is a web app; a native APK remains unbuilt.
